# MartClick — lista de compras

App estático e responsivo para montar uma lista de compras. O endereço é obrigatório; ao concluir, a lista é codificada e encaminhada ao WhatsApp `+55 16 99453-6444`, sem armazenamento de dados no site.

O recurso de áudio é apenas informativo nesta versão: não grava, envia ou armazena áudio.
